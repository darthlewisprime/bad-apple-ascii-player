Thank you for checking out my first-ever coding project!! <3
This is a lightweight Windows Batch (.bat) player designed to run smoothly
even on low-RAM laptops, streaming the entire Bad Apple!! shadow animation
live in ASCII inside your terminal with multiple synced audio modes.

------------------------------------------------------------------------
  FEATURES
------------------------------------------------------------------------
* Live ASCII Stream: Streams Bad Apple!! directly in Windows Terminal / CMD.
* Multiple Audio Options:
  - [ENTER] Silent ASCII mode (instant start)
  - [M]     Synced local audio via VLC Media Player [V] or Windows Media
            Player [W] (auto-finds "Bad Apple!!.mp3" in Downloads, Music,
            or the same folder!)
  - [B]     In-terminal Retro Chiptune Beep melody (zero audio file needed)
  - [Y]     Opens the official Bad Apple!! video on YouTube + auto-starts
  -     Opens Bad Apple!! on Spotify + auto-starts
* Low-RAM Protection: Prevents accidental double-opens from lagging your PC,
  plus an instant [C] emergency close kill-switch.
* Hidden Easter Egg: Can you find the secret mini-game? (Hint: press [G]!)

------------------------------------------------------------------------
  CONTROLS
------------------------------------------------------------------------
  [S]  Skip countdown / sync wait or skip straight to the credits screen
  [C]  Emergency close all terminal & media windows
  [R]  Replay from the credits screen
  [Y]  Open my YouTube channel (@XxAngelUzixX) from the credits screen

------------------------------------------------------------------------
  HOW TO USE & SAFETY
------------------------------------------------------------------------
1. Double-click the .bat file to launch (requires an internet connection
   for the ASCII stream).
2. Optional: Put a "Bad Apple!!.mp3" file in your Downloads folder or next
   to the .bat file if you want to use Option [M] with VLC / Media Player.
3. Want to check the source code yourself? It's 100% open and safe—just
   rename the file extension from .bat to .txt and open it in Notepad!
